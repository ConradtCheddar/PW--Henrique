oq é JavaScript

é uma linguagem de programação, interpretada, para desenvolvimento web que é executada no navegador do cliente em uma sandbox, que limita o acesso aos recursos do sistema operacional, fornecendo interfaces predefinidas, a forma de acesso a recurssos do sistema se faz por meio de objetos globais disponibilizados ao navegador, como: document, hystory, local storage e console. ela foi criada para adicionar dinamismo e interatividade nas paginas. a tipagem é dinamica e forte, permitindo que variaveis possam ser atribuidas e reatribuidas a qualquer momento , sem a necessidade de declarar seu tipo previamente. os tipos de dados nativos da linguagem são: Number, String, boolean, object, array e function
